# Rulebook

Every price-action rule as dials with fixed values. Generated by `python -m lab.dials` from `lab/dials.py`; the machine-readable copy is `rulebook_spec.json` (locked by sha256 in `config/amendments.json`). Change a value only through a numbered amendment written before looking at any result.

**Valid versions: 592,111,296,000**

## Charts

Setup charts: `1m`, `5m`, `15m`, `1h`, `4h`, `daily`. Trigger chart: the same chart or one or two steps lower; daily setups trigger on `1h`.

| setup chart | trigger chart | meaning |
|---|---|---|
| `1m` | `1m` | same chart |
| `5m` | `5m` | same chart |
| `5m` | `1m` | 1 step(s) lower |
| `15m` | `15m` | same chart |
| `15m` | `5m` | 1 step(s) lower |
| `15m` | `1m` | 2 step(s) lower |
| `1h` | `1h` | same chart |
| `1h` | `15m` | 1 step(s) lower |
| `1h` | `5m` | 2 step(s) lower |
| `4h` | `4h` | same chart |
| `4h` | `1h` | 1 step(s) lower |
| `4h` | `15m` | 2 step(s) lower |
| `daily` | `1h` | daily setup, 1h trigger |

## Fixed rules (not dials)

- **swing** - A swing high is a bar whose high is above the highs of `swing_strength` bars on each side; confirmed only once the right-side bars have closed.
- **trend** - Up when the last two confirmed swing highs and lows are both higher; down when both lower; otherwise range.
- **break_of_structure** - The first close beyond the last confirmed swing in the direction of the trend.
- **change_of_character** - The first close beyond the last confirmed swing against the trend.
- **atr** - Wilder's 14-bar ATR of the chart in use, computed only from bars before the current one.
- **higher_chart_use** - A higher-chart bar is visible only from its close (ts_avail).
- **roll** - No entries in the 60 minutes before a roll; an open trade closes at the close of the last bar before it.
- **warmup** - Warm-up sessions build detector state only; nothing is traded.
- **time_exit_bars** - bars_24 / bars_96 count trigger-chart bars from the entry bar.

## Setups

| setup | meaning | own dials |
|---|---|---|
| `level_bounce` | Price returns to a support/resistance level and rejects it. | `level_tol_atr`, `level_min_touches`, `level_shape` |
| `breakout` | First close through a level (BOS-style), trade in break direction. | `level_tol_atr`, `level_min_touches`, `level_shape` |
| `flip_zone` | A broken level is retested from the other side and holds. | `level_tol_atr`, `level_min_touches`, `level_shape`, `retest_window_bars` |
| `trend_pullback` | In a trend, price pulls back then the trigger chart resumes the trend. | - |
| `trend_line` | A trend line through swings is touched or broken. | `trendline_min_touches`, `trendline_tol_atr`, `trendline_event` |
| `bos_continuation` | Break of structure with the trend; enter on the continuation. | - |
| `choch_reversal` | Change of character: first close past the last swing against the trend. | - |
| `sweep_reclaim` | Price pokes beyond a level, then closes back inside it. | `level_tol_atr`, `level_min_touches`, `level_shape`, `sweep_depth_max_atr`, `reclaim_bars` |
| `supply_demand_zone` | Price returns to the base of a strong candle run. | `zone_run_candles`, `zone_span_atr`, `zone_fresh_only` |
| `fair_value_gap` | Price returns into a three-candle imbalance. | `fvg_min_gap_atr`, `fvg_max_age_bars` |

## Detector dials

### `swing_strength`

Bars on each side a swing high/low must out-reach to count as a confirmed swing.

| value | meaning |
|---|---|
| `2` | 2 bars each side: fast, many swings |
| `3` | 3 bars each side |
| `5` | 5 bars each side |
| `8` | 8 bars each side: slow, only major swings |

### `level_tol_atr`

Swings within this many ATR of each other cluster into one level.

| value | meaning |
|---|---|
| `0.1` | tight cluster: 0.1 ATR |
| `0.25` | medium cluster: 0.25 ATR |
| `0.5` | wide cluster: 0.5 ATR |

### `level_min_touches`

Swings a cluster needs before it is a level.

| value | meaning |
|---|---|
| `1` | a single swing is a level |
| `2` | two touches |
| `3` | three touches |
| `4` | four touches |

### `level_shape`

How a level is drawn.

| value | meaning |
|---|---|
| `line` | one price: the mean of the clustered swings |
| `box` | a band from the lowest to the highest clustered swing |

### `trendline_min_touches`

Swings a trend line must pass through (within tolerance).

| value | meaning |
|---|---|
| `2` | two swings define the line |
| `3` | a third swing confirms it |
| `4` | four swings |

### `trendline_tol_atr`

How far a swing may sit from the line and still count as a touch.

| value | meaning |
|---|---|
| `0.1` | 0.1 ATR |
| `0.25` | 0.25 ATR |
| `0.5` | 0.5 ATR |

### `zone_run_candles`

Length of the same-direction candle run that leaves a supply/demand zone.

| value | meaning |
|---|---|
| `2` | 2-candle run |
| `3` | 3-candle run |
| `4` | 4-candle run |
| `5` | 5-candle run |

### `zone_span_atr`

Minimum distance the run must cover, in ATR, for its base to be a zone.

| value | meaning |
|---|---|
| `1.5` | run covers at least 1.5 ATR |
| `2.0` | at least 2 ATR |
| `2.5` | at least 2.5 ATR |
| `3.0` | at least 3 ATR |

### `fvg_min_gap_atr`

Smallest three-candle fair value gap kept (candle 1 wick to candle 3 wick).

| value | meaning |
|---|---|
| `0.0` | any gap |
| `0.1` | gap at least 0.1 ATR |
| `0.25` | gap at least 0.25 ATR |


## Setup-specific dials

### `retest_window_bars`

Flip zone: setup-chart bars allowed between the break and the retest.

| value | meaning |
|---|---|
| `6` | retest within 6 bars |
| `12` | within 12 bars |
| `24` | within 24 bars |
| `48` | within 48 bars |

### `sweep_depth_max_atr`

Sweep and reclaim: deepest allowed poke beyond the level, in ATR.

| value | meaning |
|---|---|
| `0.25` | shallow sweep, up to 0.25 ATR |
| `0.5` | up to 0.5 ATR |
| `1.0` | deep sweep, up to 1 ATR |

### `reclaim_bars`

Sweep and reclaim: setup-chart bars allowed to close back inside the level.

| value | meaning |
|---|---|
| `1` | reclaim on the sweep bar itself |
| `2` | within 2 bars |
| `3` | within 3 bars |

### `trendline_event`

Trend line: trade the touch or the break.

| value | meaning |
|---|---|
| `bounce` | trade a touch of the line in the line's direction |
| `break` | trade the first close through the line |

### `zone_fresh_only`

Supply/demand zone: only the first return counts.

| value | meaning |
|---|---|
| `yes` | first touch only; a zone is spent once touched |
| `no` | any touch until price closes through the zone |

### `fvg_max_age_bars`

Fair value gap: setup-chart bars a gap stays tradable.

| value | meaning |
|---|---|
| `24` | gap expires after 24 bars |
| `96` | gap expires after 96 bars |


## Shared dials

### `direction`

Which side the version may trade.

| value | meaning |
|---|---|
| `long` | longs only |
| `short` | shorts only |
| `both` | longs and shorts |

### `confirmation`

What the trigger chart must print at the level before entry.

| value | meaning |
|---|---|
| `none` | enter on the touch/break itself |
| `close_back` | a trigger bar closes back on the trade side of the level |
| `rejection_wick` | a trigger bar with a wick into the level of at least half its range |
| `engulfing` | a trigger bar whose body engulfs the prior bar's body, in trade direction |
| `either_candle` | rejection wick or engulfing, whichever comes first |
| `ltf_bos` | a break of structure in trade direction on the chart below the trigger chart |

### `entry`

How the order is placed once confirmed.

| value | meaning |
|---|---|
| `close` | market at the confirming bar's close |
| `limit_at_level` | limit order back at the level; cancelled if not filled by the time exit |

### `stop_mode`

How the stop is triggered.

| value | meaning |
|---|---|
| `hard` | stop order: filled when any trade bar trades through it |
| `close_based` | exit at the close of the first trigger bar that closes beyond it |

### `stop_ref`

What the stop sits beyond.

| value | meaning |
|---|---|
| `beyond_level` | the far side of the level/zone/line |
| `touch_wick` | the extreme of the bar(s) that touched the level |
| `last_swing` | the last confirmed swing against the trade |
| `gap_middle` | the far end of the fair value gap's middle candle (FVG only) |

### `stop_buffer_atr`

Extra room added beyond the stop reference, in ATR.

| value | meaning |
|---|---|
| `0.0` | no buffer |
| `0.1` | 0.1 ATR |
| `0.25` | 0.25 ATR |

### `target`

Profit target.

| value | meaning |
|---|---|
| `1R` | 1 x risk |
| `1.5R` | 1.5 x risk |
| `2R` | 2 x risk |
| `3R` | 3 x risk |
| `4R` | 4 x risk |
| `5R` | 5 x risk |
| `next_swing` | the next confirmed swing in trade direction (skip if under 1R) |

### `management`

What happens between entry and exit.

| value | meaning |
|---|---|
| `hold` | hold to stop, target or time exit |
| `exit_on_choch` | also exit at the close of a trigger-chart change of character against the trade |

### `time_exit`

Latest exit if neither stop nor target is hit.

| value | meaning |
|---|---|
| `flat_1600` | flat at the 16:00 ET bar close |
| `bars_24` | after 24 trigger-chart bars |
| `bars_96` | after 96 trigger-chart bars |


## Filters

### `trend_filter`

Trade only when this chart's trend (last two swing highs and lows) agrees.

| value | meaning |
|---|---|
| `off` | no trend filter |
| `setup_chart` | trend on the setup chart agrees |
| `one_up` | trend on the next chart up agrees |
| `daily` | daily trend agrees |

### `skip_choppy`

Skip days the prior session was choppy (|close-open| < 30% of its range).

| value | meaning |
|---|---|
| `off` | trade every day |
| `on` | skip after a choppy session |

### `skip_run`

Skip trades in the direction of a run of same-direction daily closes.

| value | meaning |
|---|---|
| `off` | no run filter |
| `3d` | skip with a 3-day run |
| `5d` | skip with a 5-day run |

### `fresh_breakouts_only`

Only the first close through a level since the level formed.

| value | meaning |
|---|---|
| `off` | any break |
| `on` | first break only |

### `news`

What to do on CPI, jobs-report and FOMC days.

| value | meaning |
|---|---|
| `trade` | trade normally |
| `skip` | no new entries that session |
| `half` | half position size that session |

### `session`

Entry time window (ET).

| value | meaning |
|---|---|
| `all` | any time in the session |
| `london_ny` | 03:00 to 16:00 |
| `ny` | 08:00 to 16:00 |
| `ny_open` | 09:30 to 11:00 |

### `pullback_depth`

Retracement of the last impulse leg on the setup chart.

| value | meaning |
|---|---|
| `any` | no depth filter |
| `shallow` | under 50% of the leg |
| `deep` | 50% to 100% of the leg |

### `gap_confluence`

Entry level must sit inside an unfilled setup-chart fair value gap.

| value | meaning |
|---|---|
| `off` | no gap needed |
| `on` | gap confluence required |

## Combinations removed

| id | when | removes | why |
|---|---|---|---|
| X1 | if setup_chart in ['4h', 'daily'] | time_exit = flat_1600 | A flat-at-16:00 exit cuts a 4h or daily setup before it can play out. |
| X2 | if trigger_chart in ['1m'] | confirmation = ltf_bos | There is no chart below 1m for a lower-chart break of structure. |
| X3 | if setup_chart in ['daily'] | trend_filter = one_up, daily | No chart above daily, and 'daily' would repeat 'setup_chart'. |
| X4 | if setup_chart in ['4h'] | trend_filter = one_up | One chart up from 4h is daily, which the 'daily' value already covers. |
| X5 | if trigger_chart in ['4h'] | session = ny_open | Only one 4h close (10:00) falls inside 09:30-11:00, so the window is not a filter but a single bar. |
| X6 | unless setup in ['fair_value_gap'] | stop_ref = gap_middle | Only a fair value gap has a middle candle. |
| X7 | if setup in ['fair_value_gap'] | gap_confluence = on | The setup already is a gap; confluence with itself is no filter. |
| X8 | unless setup in ['breakout', 'flip_zone'] | fresh_breakouts_only = on | Fresh-breakout filter only applies to setups built on a level break. |
| X9 | unless setup in ['trend_pullback', 'flip_zone', 'bos_continuation'] | pullback_depth = shallow, deep | Pullback depth only applies to setups entered on a pullback. |

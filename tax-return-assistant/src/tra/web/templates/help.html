Help

Doing a return in Sawnx

  1. New client (the green + at the top): the client's name; the code is suggested from the surname.
  2. Files → Import documents: Individual, then for each file Read for the return or Store only. Numbers like TFNs are blanked out the moment a file is read.
  3. Figures: tick Confirmed for each figure once you've checked it against the document beside it.
  4. Prepare: one button. It shows the refund or payable and both calculations, and makes the Excel workpaper.
  5. Review notes: answer each note, tick Resolved, then Mark reviewed. A registered tax agent signs the workpaper's Cover tab. Nothing is ever lodged from Sawnx.

Finding things

  • Home → My Recent lists documents by when they were filed or last described. Star the ones you're working on; they appear under My Starred.
  • Documents lists everything. Click a column heading to sort; use the filters to narrow it down.
  • Tick several documents to star, download or move them together (moving works within one client and year).

Privacy

Sawnx runs only on this laptop. Client names appear on screen, but files, folders, logs and workpapers use the client code. If Sawnx ever refuses to save something because it looks like a TFN or account number, tell the privacy officer.

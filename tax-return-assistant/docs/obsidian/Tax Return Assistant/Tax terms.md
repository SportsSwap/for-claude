# Tax terms

Back to [[Tax Return Assistant]]

| Term | Meaning |
|---|---|
| **TFN** | Tax file number. Never stored by the tool. |
| **Pre-fill report** | The ATO's data on the client (income statements, interest, dividends, health insurance), downloaded from Online services for agents |
| **Income statement** | Employer's year-end summary of salary and PAYG withheld (replaced payment summaries) |
| **PAYG withheld** | Tax the employer already took out of wages |
| **Franking credit** | Company tax already paid on a dividend. Added to income, then refunded or offset. |
| **LITO** | Low income tax offset: up to $700 |
| **SAPTO** | Seniors and pensioners tax offset |
| **Medicare levy** | 2% of taxable income, reduced for low incomes |
| **MLS** | Medicare levy surcharge: an extra 1–1.5% if income is high and there's no private hospital cover |
| **PHI rebate** | Government rebate on private health insurance premiums. The amount depends on income tier and age. |
| **HELP** | Study loan. Compulsory repayments are worked out from repayment income; a new marginal system applies from 2025–26. |
| **D1–D15** | Deduction labels: D1 car, D2 travel, D3 clothing, D4 self-education, D5 other work-related, D7 interest, D8 dividend, D9 gifts, D10 tax affairs, D12 personal super, D15 other |
| **Substantiation** | Written evidence for work claims. Needed once the total is over $300 (s900-35). |
| **CGT discount** | 50% off a capital gain on assets held over 12 months (residents) |
| **Net rent** | Gross rent less rental deductions. Can be negative (negative gearing). |
| **Item 15 / P8** | Business income and the business schedule, for sole traders (from Xero) |
| **ITAA 1997** | Income Tax Assessment Act 1997, the main tax law |
| **TR / PCG** | ATO tax rulings and practical compliance guidelines |
| **TASA / TPB** | Tax Agent Services Act 2009 / Tax Practitioners Board, which set the agents' Code of Conduct |
| **APP** | Australian Privacy Principles (Privacy Act 1988) |
